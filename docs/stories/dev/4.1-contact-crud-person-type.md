# Story 4.1: Contact Crud Person Type — Contacts

## Story

As a job seeker,
I want to add and delete a Person contact per application,
so that I can keep track of recruiters/interviewers I've spoken with.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given the Contacts tab, when I add a contact with a name, then it saves and appears in the list.
2. Given a contact, when I delete it, then it's removed immediately.
