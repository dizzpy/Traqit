# Story 2.5: Activity Log On Status Change — Applications (Core Tracker)

## Story

As a job seeker,
I want every status change to be recorded in an activity timeline,
so that I can see the history of an application at a glance.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given an application's status changes, when I open its Activity tab, then a new entry appears with the old and new status.
2. Given multiple changes over time, when I view Activity, then entries are ordered chronologically.

  - [x] Confirm status-change writes to Activity in `applications/[id]/route.ts`
