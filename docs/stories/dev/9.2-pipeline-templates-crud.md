# Story 9.2: Pipeline Templates Crud — Presets

## Story

As a job seeker with a repeatable process,
I want to create, edit, and delete reusable pipeline templates,
so that I can quickly apply a known stage sequence to new applications.

## Acceptance Criteria

1. Given the Templates page, when I create a template with a name and stage list, then it saves and is selectable when adding/editing an application.
2. Given an existing template, when I edit its stage list, then future applications of it use the updated list (does not retroactively change already-applied applications).
