# Story 3.3: Pipeline Stage Scheduled Date — Pipeline Stages

## Story

As a job seeker,
I want to set an optional scheduled date on a pipeline stage,
so that upcoming interviews show up on my calendar.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given a stage, when I set a scheduled date, then it saves and appears on the Calendar view.
2. Given a stage with no date, when viewed, then it does not appear on the calendar.
