# Story 3.4: Apply Pipeline Template To Application — Pipeline Stages

## Story

As a job seeker with a repeatable interview process,
I want to apply a saved pipeline template to an application,
so that I don't have to manually recreate the same stage list every time.

**Status:** ⚠️ Partially implemented — verified against code on `main`.

## Acceptance Criteria

1. Given a saved template, when I apply it to an application, then the application's existing stages are replaced with the template's stage list.
2. Given a template application, when confirmed, then this is a destructive replace, not a merge — user should be warned before existing stages are lost.

## Tasks / Subtasks

- [ ] Verify template apply logic
  - [ ] Confirm existing stages are deleted then recreated from the template's Json array
  - [ ] Confirm/add a confirmation step before destructive replace, if not already present
