# Story 1.3: Admin Allowlist Access Control — Auth & Authorization

## Story

As the founder,
I want only my allowlisted email(s) to access the internal admin dashboard,
so that regular users can never see or reach internal analytics.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given a non-admin user, when they navigate to `/app/admin/dizzpy`, then they receive a 404, not a 403.
2. Given an admin email (from `ADMIN_EMAILS` env var), when they navigate to `/app/admin/dizzpy`, then the dashboard loads.

## Tasks / Subtasks

- [x] Verify allowlist logic
  - [x] Confirm `isAdminEmail()` in `src/lib/admin.ts` reads `ADMIN_EMAILS` correctly
  - [x] Confirm the page returns `notFound()` rather than a 403 for non-admins
