# Story 1.1: Magic Link Github Oauth Signin — Auth & Authorization

## Story

As an unauthenticated visitor,
I want to sign in via magic link or GitHub OAuth,
so that I can access my Traqit account without managing a separate password.

## Acceptance Criteria

1. Given the login page, when I enter my email and request a magic link, then I receive an email with a working sign-in link.
2. Given the login page, when I choose 'Continue with GitHub', then I complete OAuth and land on `/app/applications`.
3. Given an already-authenticated user, when they visit `/login`, then they are redirected to `/app/applications` instead of seeing the form.

## Tasks / Subtasks

  - [ ] Confirm magic link + GitHub OAuth both work end-to-end against current Supabase Auth config
  - [ ] Confirm `/login` redirect-if-authenticated logic in `src/app/(auth)/login/page.tsx`
