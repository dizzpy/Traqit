# Story 13.1: Admin Dashboard Analytics — Admin Dashboard

## Story

As the founder,
I want an internal dashboard showing signup growth, retention, and per-company response/ghost rates,
so that I can understand product health without querying the database directly.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given the admin dashboard, when loaded, then it shows new-user counts for today/7d/30d.
2. Given the members table, when viewed, then it's sortable and shows per-user activity.
