# Story 2.4: Bulk Select Bulk Soft Delete — Applications (Core Tracker)

## Story

As a job seeker cleaning up old entries,
I want to select multiple applications and delete them at once,
so that I don't have to delete rows one at a time.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given multiple rows selected via checkboxes, when I trigger bulk delete, then all selected rows are soft-deleted in a single request.
2. Given a bulk delete just performed, when I check Trash, then all deleted rows appear there.
