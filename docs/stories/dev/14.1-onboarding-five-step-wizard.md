# Story 14.1: Onboarding Five Step Wizard — Onboarding & Tour

## Story

As a first-time user,
I want a guided 5-step setup wizard on my first login,
so that I understand how to start using Traqit without guessing.

## Acceptance Criteria

1. Given a first-time login, when I land in the app, then the onboarding wizard starts automatically.
2. Given I complete all 5 steps, when finished, then `Profile.onboardedAt` is set and I don't see the wizard again.

## Tasks / Subtasks

- [ ] Verify existing wizard
  - [ ] Confirm gating via `onboardedAt` in `layout.tsx` and `auth/callback/route.ts`
