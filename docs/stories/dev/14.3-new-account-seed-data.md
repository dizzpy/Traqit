# Story 14.3: New Account Seed Data — Onboarding

## Story

As a new user,
I want my account to start with sensible defaults and a few example applications,
so that the app isn't a blank page and I can see how it works.

**Status:** ✅ Verified implemented (code-inspected, 2026-10-07). Story written after the fact so QA has a checklist.
**SRS:** FR-14.3 in `docs/srs.md`

## Acceptance Criteria

1. Given a brand-new account, when the profile is created, then default sources, job types, pipeline templates and outreach templates exist.
2. Given a brand-new account, when I open Applications, then a few example applications appear across different statuses, with stages, a contact and activity.
3. Given an account that already has applications, when seeding runs again, then no example applications are added.
4. Given an example application, when I delete it, then it behaves like any other application (Trash, restore).

## Tasks / Subtasks

- [x] Verify seeding
  - [x] Confirm `seedProfile()` runs on profile creation (`src/lib/auth.ts`)
  - [x] Confirm `seedSampleApplications()` no-ops when the profile already has applications
