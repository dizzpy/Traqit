# Story 2.3: Search Sort Filter Column Visibility — Applications (Core Tracker)

## Story

As a job seeker with many applications,
I want to search, sort, filter, and hide/show table columns,
so that I can find and focus on what matters without scrolling through everything.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given the search box, when I type a company or position name, then the list filters to matching rows.
2. Given the column header, when I click to sort, then the list re-orders and toggles direction on repeated clicks.
3. Given the column visibility control, when I hide a column, then it disappears from the table and the preference persists.
