# Story 7.1: Readonly Calendar Agenda View — Calendar

## Story

As a job seeker,
I want a calendar view of all my upcoming interview stage dates,
so that I can see my schedule at a glance across all applications.

**Status:** ✅ Verified implemented on `main` (code-inspected).
**SRS:** FR-7.1, FR-7.2 in `docs/srs.md`

## Acceptance Criteria

1. Given pipeline stages with scheduled dates, when I open Calendar, then each appears on its correct day in the month grid.
2. Given the list view of the calendar, when toggled, then the same events appear in agenda/list form.

## Implementation Notes

- Doc correction (2026-10-07): the calendar was never read-only. It shows stages **and application deadlines**; clicking an event opens the detail panel; removing an event (with a confirmation dialog) deletes the stage or clears the deadline. Product owner chose to keep this and update the SRS (FR-7.1, FR-7.2).
- With story 3.5, timed stages show their time, and all-day stages land on the correct local day.
