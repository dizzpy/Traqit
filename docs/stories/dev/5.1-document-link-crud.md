# Story 5.1: Document Link Crud — Documents

## Story

As a job seeker,
I want to add and delete named document links per application,
so that I can keep my CV/cover letter links attached to the relevant application.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given the Documents tab, when I add a label and a link, then it saves and appears in the list.
2. Given a document, when I delete it, then it's removed immediately.
