# Story 8.1: Manual Ghost Status Visual Flagging — Ghost Detection

## Story

As a job seeker,
I want applications with no response past my threshold to be visually flagged,
so that I can spot likely-ghosted applications without manually checking dates.

## Acceptance Criteria

1. Given an APPLIED application with no response past the configured ghost threshold, when I view the list, then the row is visually dimmed with an explanatory tooltip.
2. Given a user's configured ghost threshold (in Settings), when changed, then the flagging recalculates against the new threshold.
3. Given the manual GHOSTED status, when a user sets it explicitly, then it's a distinct, deliberate action separate from the passive dimming.

## Tasks / Subtasks

- [ ] Verify flagging logic
  - [ ] Confirm the client-side flagging calculation matches `Profile.ghostThresholdDays`
  - [ ] Confirm this never auto-writes to the database (visual only, per current scope)
