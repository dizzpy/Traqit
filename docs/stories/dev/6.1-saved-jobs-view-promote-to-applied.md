# Story 6.1: Saved Jobs View Promote To Applied — Saved Jobs

## Story

As a job seeker browsing openings,
I want to save jobs for later and promote them to Applied when I actually apply,
so that I can keep a shortlist separate from my active applications.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given a job saved with status SAVED, when I view the Saved page, then it appears there and not in the main Applications list by default.
2. Given a saved job, when I click 'Promote to Applied', then its status changes to APPLIED and it leaves the Saved list.
