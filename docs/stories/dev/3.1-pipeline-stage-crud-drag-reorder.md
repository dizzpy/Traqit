# Story 3.1: Pipeline Stage Crud Drag Reorder — Pipeline Stages

## Story

As a job seeker,
I want to add, remove, and drag-reorder interview stages on an application,
so that I can track my exact interview process for each role.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given an application's Pipeline tab, when I add a stage, then it appears at the end of the list.
2. Given multiple stages, when I drag to reorder, then the new order persists after reload.
3. Given a stage still mid-create (temp id), when reorder is attempted, then it's guarded against acting on an unsaved stage.

## Dev Notes

- `PipelineStage` deliberately has no unique constraint on (applicationId, order) — bulk reordering via incremental updates would trip it mid-statement. Order is a sort key, not a strict invariant. [Source: `current-state.md#Data Model`]
