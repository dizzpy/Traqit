# Story 5.3: Document Edit Route — Documents

## Story

As a job seeker,
I want to edit a document's label (and replace its link or file),
so that I don't have to delete and recreate it for a small correction.

**Status:** ❌ Not started — verified against code on `main`, no implementation found.

## Acceptance Criteria

1. Given an existing document, when I edit its label, then the change saves in place.
2. Given a link-type document, when I edit its URL, then the new URL saves without creating a new record.
