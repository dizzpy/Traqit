# Story 5.3: Document Edit Route — Documents

## Story

As a job seeker,
I want to edit a document's label (and replace its link or file),
so that I don't have to delete and recreate it for a small correction.

**Status:** ✅ Implemented on `fix/storie-issues` (2026-10-07), awaiting QA.
**SRS:** FR-5.3 in `docs/srs.md`

## Acceptance Criteria

1. Given an existing document, when I edit its label, then the change saves in place.
2. Given a link-type document, when I edit its URL, then the new URL saves without creating a new record.

## Implementation Notes

- Scope decision: uploaded documents can have their **file replaced**, not just their label.
- `PATCH .../documents/[documentId]` takes JSON (name/type, plus URL for link documents only) or multipart (file replacement, upload documents only).
- Replace stores the new file first, updates the row, then deletes the old file. A failed DB update removes the new file, so the original stays intact.
- UI: `AddDocumentForm` became a shared `DocumentForm`; editing happens in place on the card.
