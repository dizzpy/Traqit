# Story 2.1: Application Crud Soft Delete — Applications (Core Tracker)

## Story

As a job seeker,
I want to create, view, edit, and soft-delete job applications,
so that I can track my job search without losing data by accident.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given the Add Application form, when I submit valid required fields (company, position, job type, applied via), then the application is created and appears in the list.
2. Given an existing application, when I edit any field, then the change persists and reflects immediately (optimistic update).
3. Given an application, when I delete it, then it is soft-deleted (`deletedAt` set) and a 5-second Undo toast appears.

## Tasks / Subtasks
