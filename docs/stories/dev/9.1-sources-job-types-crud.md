# Story 9.1: Sources Job Types Crud — Presets

## Story

As a job seeker,
I want to create, edit, and delete my own custom Sources and Job Types,
so that my dropdowns reflect terms that actually make sense for my search.

## Acceptance Criteria

1. Given the presets UI, when I add a new Source or Job Type, then it appears in the relevant dropdown immediately.
2. Given a duplicate name within the same profile, when I attempt to add it, then it's rejected (unique constraint).
