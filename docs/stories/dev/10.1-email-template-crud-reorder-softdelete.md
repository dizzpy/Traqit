# Story 10.1: Email Template Crud Reorder Softdelete — Email Templates

## Story

As a job seeker,
I want to create, reorder, and delete outreach email templates,
so that I can reuse my best-performing outreach messages.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given the Templates page, when I create a template, then it saves and appears in the list.
2. Given multiple templates, when I drag to reorder, then the new order persists.
3. Given a template, when I delete it, then it's soft-deleted and recoverable via Trash.
