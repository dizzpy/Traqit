# Story 10.2: Placeholder Substitution Gmail Draft — Email Templates

## Story

As a job seeker,
I want my outreach templates to auto-fill placeholders and open as a Gmail draft,
so that I can send outreach quickly without retyping details.

## Acceptance Criteria

1. Given a template with placeholders (`{company}`, `{position}`, `{contact}`, `{myName}`, `{jobUrl}`), when I use it on an application, then all placeholders are substituted with that application's actual data.
2. Given a completed draft, when I click send, then a Gmail compose window opens pre-filled, in a new tab — the user must still click send in Gmail themselves.

## Tasks / Subtasks

- [ ] Verify substitution + compose URL
  - [ ] Confirm all 5 placeholders resolve correctly in `src/lib/email.ts`
  - [ ] Confirm this is clearly communicated as a compose-assist, not an auto-send, in the UI copy

## Dependencies

**Prerequisites:** 10.1
**Blocks:** None.

## Dev Notes

- This is not a real Gmail API integration — it's a `mail.google.com` compose-URL builder. No OAuth, no automated send exists. UI copy should not imply otherwise. [Source: `current-state.md#External Dependencies`]

### Project Structure Notes

- Expected files:
  - `src/lib/email.ts`
  - `src/components/application/draft-email-modal.tsx`
  - `src/components/application/email-preview.tsx`

### Architecture Compliance

- Functionally equivalent to a mailto: link with a pre-filled body; no server-side send capability.

### Testing Requirements

- Apply a template to an application with all fields populated, confirm every placeholder resolves correctly and the Gmail draft opens.
