# Story 4.3: Contact Edit Route — Contacts

## Story

As a job seeker,
I want to edit an existing contact in place,
so that I don't have to delete and recreate it just to fix a typo.

**Status:** ✅ Implemented on `fix/storie-issues` (2026-10-07), awaiting QA.
**SRS:** FR-4.3 in `docs/srs.md`

## Acceptance Criteria

1. Given an existing contact, when I click edit and change a field, then the change saves without deleting/recreating the record.
2. Given an edit in progress, when I cancel, then no changes are persisted.

## Tasks / Subtasks

- [x] Add PATCH route
  - [x] Add `PATCH /api/applications/[id]/contacts/[contactId]`
  - [x] Add edit affordance in the contacts UI (reuse the add-contact form in edit mode)

## Dev Notes

### Architecture Compliance

- Reuses existing contact form component in an edit mode, prefilled with current values.

### Testing Requirements

- Edit a Person and a Company contact, confirm both save correctly without losing unrelated fields.

## Implementation Notes

- `PATCH .../contacts/[contactId]` validates role against the merged state, so switching Company → Person without a role is rejected.
- `AddContactForm` became a shared `ContactForm`; editing swaps that contact's card for the prefilled form in place.
