# Story 4.3: Contact Edit Route — Contacts

## Story

As a job seeker,
I want to edit an existing contact in place,
so that I don't have to delete and recreate it just to fix a typo.

## Acceptance Criteria

1. Given an existing contact, when I click edit and change a field, then the change saves without deleting/recreating the record.
2. Given an edit in progress, when I cancel, then no changes are persisted.

## Tasks / Subtasks

- [ ] Add PATCH route
  - [ ] Add `PATCH /api/applications/[id]/contacts/[contactId]`
  - [ ] Add edit affordance in the contacts UI (reuse the add-contact form in edit mode)

## Dependencies

**Prerequisites:** 4.1, 4.2
