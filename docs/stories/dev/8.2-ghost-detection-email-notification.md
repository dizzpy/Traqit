# Story 8.2: Ghost Detection Email Notification — Ghost Detection

## Story

As a job seeker,
I want to receive an email when an application is detected as likely ghosted,
so that I don't have to keep checking the app manually to notice.

**Status:** ✅ Implemented on `fix/storie-issues` (2026-10-07), awaiting QA.
**SRS:** FR-8.2, FR-12.6 in `docs/srs.md`

## Acceptance Criteria

1. Given an application crosses the ghost threshold, when the scheduled check runs, then an email is sent to the user notifying them of the specific application.
2. Given a user has already been notified for a given application, when the check runs again, then they are not notified a second time for the same occurrence.
3. Given a user disables reminders/notifications in settings, when the check runs, then no email is sent to them.

## Dev Notes

- Uses Resend (free tier) + React Email + a Supabase pg_cron job calling a Next.js API route, reusing the existing trash-purge cron pattern. [Source: chat decision]
- Needs a 'notified' flag or timestamp on Application to prevent duplicate emails for the same ghost event — not currently in the schema.

### Project Structure Notes

### Testing Requirements

## Implementation Notes

- Nodemailer over SMTP (`src/lib/mailer.ts`, server-only) instead of Resend. Switching provider is an env change.
- `/api/cron/ghost-check` (POST, `Authorization: Bearer <CRON_SECRET>`; 503 if SMTP isn't configured).
- Same rule as the table's "Nd silent" badge (FR-8.1). One digest email per user per run, listing every newly-eligible application.
- Dedupe via new `Application.ghostNotifiedAt`: claimed before sending, released if the send fails. Cleared when `appliedDate` changes (new occurrence).
- Uses the existing reminders toggle as the opt-out (AC3); its label is now "Email me about interviews and quiet applications".
- Schedule: `prisma/sql/pg_cron_notifications.sql` (every 15 min, pg_net, URL + secret in Supabase Vault). **Not installed on any environment yet.**
- Setup per environment: env `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `EMAIL_FROM`, `CRON_SECRET`; run `prisma/sql/add_notification_tracking_fields.sql` and `pg_cron_notifications.sql`.
