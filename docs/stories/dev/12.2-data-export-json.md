# Story 12.2: Data Export Json — Settings, Profile & Notifications

## Story

As a user who wants a personal backup,
I want to export all my data as a JSON download,
so that I have a copy outside of Traqit if I ever need it.

## Acceptance Criteria

1. Given the Settings page, when I click Export, then a JSON file downloads containing my applications, stages, contacts, documents, and activity.
