# Story 16.2: Github Actions Ci Pipeline — CI/CD & Tooling

## Story

As a developer merging changes to main,
I want a CI pipeline that lints, typechecks, and builds on every push/PR,
so that broken code can't land on main even if local hooks are bypassed.

## Acceptance Criteria

1. Given a push or PR, when CI runs, then it installs dependencies, runs lint, runs typecheck, and runs a production build.
2. Given any of those steps fail, when CI completes, then the PR is marked as failing and merge is blocked (if branch protection is enabled).

## Tasks / Subtasks

- [ ] Setup
  - [ ] Add `.github/workflows/ci.yml`
  - [ ] Steps: checkout, install (bun), lint, typecheck, build
  - [ ] Document enabling branch protection to require this check before merge (manual GitHub settings step, not code)

**Prerequisites:** 15.4, 16.1
