# Story 2.2: List Kanban Board Views — Applications (Core Tracker)

## Story

As a job seeker,
I want to toggle between a list view and a kanban board of my applications,
so that I can pick whichever layout fits how I'm currently thinking about my search.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given the applications page, when I toggle to board view, then applications render as cards grouped into status columns.
2. Given the board view, when I drag a card to a different column, then the application's status updates and persists.
3. Given either view, when I reload the page, then my last-selected view is remembered.
