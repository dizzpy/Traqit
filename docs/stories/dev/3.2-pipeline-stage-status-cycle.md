# Story 3.2: Pipeline Stage Status Cycle — Pipeline Stages

## Story

As a job seeker,
I want each pipeline stage to cycle through a defined status sequence,
so that I can quickly mark progress without a dropdown for every click.

**Status:** ✅ Verified implemented on `main` (code-inspected).

## Acceptance Criteria

1. Given a stage in UPCOMING, when I click its status, then it cycles to COMPLETED, then PASSED, then FAILED, then SKIPPED, then back to UPCOMING.
2. Given a status change, when saved, then it persists and reflects on reload.
