# Story 14.2: Guided Tour Keyboard Shortcuts — Onboarding & Tour

## Story

As a user familiar with the basics,
I want an in-app guided tour and keyboard shortcuts,
so that I can navigate and act faster once I know the app.

## Acceptance Criteria

1. Given I trigger the guided tour, when active, then it highlights key UI elements in sequence.
2. Given a keyboard shortcut (e.g. `a`, `s`, `c`, `g`, `n`), when pressed, then it navigates or opens the expected panel.

## Tasks / Subtasks

- [ ] Verify tour + shortcuts
  - [ ] Confirm driver.js targeting via `[data-tour=...]`
  - [ ] Confirm the pending-action hand-off for shortcuts that navigate then open a panel

## Dependencies

**Prerequisites:** 14.1
**Blocks:** None.
