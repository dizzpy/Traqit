# Story 2.6: Non Paid Salary Option — Applications (Core Tracker)

## Story

As a user tracking unpaid internships or volunteer roles,
I want to mark an application's salary as 'Non-paid',
so that unpaid roles are distinct from applications where salary just wasn't disclosed.

## Acceptance Criteria

1. Given the Add/Edit form, when I select 'Non-paid', then the salary range inputs are disabled and cleared.
2. Given a Non-paid application, when viewed in the table, then the salary column shows a distinct 'Non-paid' label, not a blank cell.
3. Given an application with no salary entered at all, when viewed in the table, then it renders as blank/undisclosed and is never visually identical to Non-paid.
