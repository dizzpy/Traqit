# Story 18.3: Pricing and FAQ Copy Accuracy — Marketing & Pricing

## Story

As a visitor deciding whether to sign up,
I want the pricing and FAQ to describe what the app really does,
so that I'm not misled about what Free includes or how ghost detection works.

**Status:** ✅ Implemented on `fix/storie-issues` (2026-10-07), awaiting QA.
**SRS:** FR-18.3 in `docs/srs.md`

## Acceptance Criteria

1. Given the Free card, when viewed, then it lists email reminders before interviews, JSON data export and a custom ghost detection threshold, because every user has these today.
2. Given the Pro card, when viewed, then it no longer lists those three features, and lists only features that don't exist yet (browser extension, advanced analytics).
3. Given the Free card, when viewed, then the ghost detection line no longer says "14-day auto-flag"; it says flagged after your threshold (default 14 days).
4. Given the FAQ, when the ghost-detection and Notion-comparison answers are read, then they say applications are **flagged** after the user's threshold, not that Traqit "automatically marks" them as ghosted.
