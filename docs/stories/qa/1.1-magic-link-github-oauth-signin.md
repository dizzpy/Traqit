# QA: Story 1.1 — Magic Link Github Oauth Signin — QA Verification

**Epic:** Auth & Authorization
**Traces to Dev Story:** 1.1-magic-link-github-oauth-signin.md

### Magic Link
- [ ] Requesting a link with a valid email sends it.
- [ ] Clicking the link signs the user in and lands on /app/applications.

### GitHub OAuth
- [ ] Completing GitHub OAuth signs the user in.
- [ ] Denying GitHub OAuth returns to /login without a broken state.

### Redirect Guard
- [ ] An already-signed-in user visiting /login is redirected away, not shown the form.

### Regression Sanity
- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
