# QA: Story 11.1 — Trash Recovery Purge Cron Lazy Sweep — QA Verification

**Epic:** Trash
**Traces to Dev Story:** 11.1-trash-recovery-purge-cron-lazy-sweep.md

### Restore
- [ ] Restoring within 30 days brings the item back with all original data intact.
- [ ] Restored applications/templates behave identically to never having been deleted.

### Purge
- [ ] Items older than 30 days are hard-deleted, unrecoverable after purge.
- [ ] Purge does not touch items still within the window.

### Regression Sanity
- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
