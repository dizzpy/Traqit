# QA: Story 2.1 — Application Crud Soft Delete — QA Verification

**Epic:** Applications (Core Tracker)
**Traces to Dev Story:** 2.1-application-crud-soft-delete.md

### Create
- [ ] Required fields enforced (company, position, job type, applied via).
- [ ] New application appears immediately in the list.

### Edit
- [ ] Inline edits persist after page refresh.
- [ ] Optimistic UI reverts correctly if the save fails.

### Soft Delete
- [ ] Deleted row disappears from the main list.
- [ ] Undo toast appears for 5 seconds and restores the row when clicked.
- [ ] After the Undo window expires, the row is not restorable from the main UI (must go through Trash).

### Regression Sanity
- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
