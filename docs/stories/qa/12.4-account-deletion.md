# QA: Story 12.4 — Account Deletion — QA Verification

**Epic:** Settings, Profile & Notifications
**Traces to Dev Story:** 12.4-account-deletion.md

### Deletion Completeness
- [ ] All Profile-owned data (applications, contacts, documents, etc.) is gone after deletion.
- [ ] No orphaned rows remain in any related table.

### Auth Cleanup
- [ ] Supabase auth user is deleted when service role key is configured.
- [ ] Deletion degrades gracefully (app-level data still deleted) if the service role key is missing.

### Confirmation
- [ ] User must explicitly confirm before this irreversible action proceeds.

### Regression Sanity
- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
