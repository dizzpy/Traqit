# QA: Story 14.1 — Onboarding Five Step Wizard — QA Verification

**Epic:** Onboarding & Tour
**Traces to Dev Story:** 14.1-onboarding-five-step-wizard.md

### First-Time Flow
- [ ] New user sees the wizard automatically.
- [ ] Completing all 5 steps sets onboardedAt and doesn't show the wizard again.

### Returning User
- [ ] An already-onboarded user never sees the wizard again, even after signing out and back in.

### Regression Sanity
- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
