**Traces to Dev Story:** 16.2-github-actions-ci-pipeline.md

### CI Execution
- [ ] CI runs automatically on push and PR.
- [ ] Lint, typecheck, and build steps all execute and report correctly.

### Failure Blocking
- [ ] A PR with a lint, type, or build error shows a failing check.

- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
