# QA: Story 17.1 — Personal Analytics Dashboard — QA Verification

**Epic:** Analytics
**Traces to Dev Story:** 17.1-personal-analytics-dashboard.md
**SRS:** FR-17.1 in `docs/srs.md`

### Rates

- [ ] With a known set of applications (e.g. 10 non-Saved: 2 Ghosted, 3 Applied, 2 In Progress, 1 Offer, 2 Rejected), response rate shows 50%, interview rate 30%, offer rate 10%.
- [ ] Saved applications don't affect any rate.
- [ ] Average days to first response only counts applications with both an applied date and a first response date.

### Charts

- [ ] The status breakdown matches the counts in the Applications list.
- [ ] Applications per week covers the last 12 weeks.
- [ ] Source effectiveness lists only sources with at least 2 applications, highest response rate first.

### Empty State

- [ ] A user with no applications sees a helpful empty state, with no NaN or broken charts.

### Regression Sanity

- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
