# QA: Story 5.3 — Document Edit Route — QA Verification

**Epic:** Documents
**Traces to Dev Story:** 5.3-document-edit-route.md
**SRS:** FR-5.3 in `docs/srs.md`

### Setup Before Testing

- Same setup as QA 5.2.

### Edit Flow

- [ ] Editing a label persists correctly.
- [ ] Editing a link's URL persists correctly.
- [ ] The document's id/created date remain unchanged after an edit.

### File Replacement and Rules

- [ ] Editing an uploaded document with a new file replaces the file; opening it downloads the new file.
- [ ] Editing an uploaded document without choosing a file keeps the current file and saves the label/type.
- [ ] Replacing with an oversized or unsupported file is rejected and the original file still opens.
- [ ] Uploaded documents show no URL field when editing; link documents show no file picker.
- [ ] Cancel discards edits.

### Regression Sanity

- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
