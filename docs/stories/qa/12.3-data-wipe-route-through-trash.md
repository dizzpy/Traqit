# QA: Story 12.3 — Data Wipe Route Through Trash — QA Verification

**Epic:** Settings, Profile & Notifications
**Traces to Dev Story:** 12.3-data-wipe-route-through-trash.md

### Wipe Behavior
- [ ] Wipe soft-deletes (moves to Trash), does not hard-delete.
- [ ] All applications for the profile are included, none skipped.

### Recovery
- [ ] Wiped applications are restorable from Trash within 30 days, identical to a manual delete.

### Confirmation
- [ ] User is clearly warned before wipe, even though it's now recoverable (avoid false sense that it's instantly reversible from the UI alone).

### Regression Sanity
- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
