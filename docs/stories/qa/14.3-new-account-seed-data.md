# QA: Story 14.3 — New Account Seed Data — QA Verification

**Epic:** Onboarding
**Traces to Dev Story:** 14.3-new-account-seed-data.md
**SRS:** FR-14.3 in `docs/srs.md`

### Defaults

- [ ] A fresh account has the default sources (e.g. LinkedIn, Referral, Indeed) and job types (e.g. Intern, Trainee SE).
- [ ] Pipeline templates "SL company", "Standard tech" and "FAANG-style" exist.
- [ ] Starter outreach templates exist on the Email templates page.

### Example Applications

- [ ] Example applications appear on first visit, across several statuses, with stages, a contact and activity.
- [ ] Signing out and back in does not add more example applications.
- [ ] Deleting an example application moves it to Trash and it can be restored.

### Regression Sanity

- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
