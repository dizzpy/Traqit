### Edit Flow

- [ ] Editing a field persists correctly.
- [ ] Canceling an edit discards changes.

- [ ] Editing a Company contact's fields works the same as Person.

- [ ] Switching a Company contact to Person without a role is rejected.

- [ ] No console errors introduced in the browser during this flow.

- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
