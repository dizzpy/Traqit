# QA: Story 1.2 — Session Route Api Auth Gating — QA Verification

**Epic:** Auth & Authorization
**Traces to Dev Story:** 1.2-session-route-api-auth-gating.md
**SRS:** FR-1.2 in `docs/srs.md`

### Page Gating

- [ ] Unauthenticated visit to any /app/* route redirects to /login.

### API Gating

- [ ] Unauthenticated call to any /api/* route returns 401.
- [ ] A sample of at least 5 different route handlers all reject unauthenticated calls.

### Header Spoofing

- [ ] A request with a manually set x-auth-user-id header is not trusted; the server's own verified value is used instead.

### Cron Exception

- [ ] `POST /api/cron/ghost-check` with no session and no secret returns 401 JSON from the route (not a redirect to /login).
- [ ] Other `/api/*` routes still return 401 without a session.

### Regression Sanity

- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
