# QA: Story 7.1 — Readonly Calendar Agenda View — QA Verification

**Epic:** Calendar
**Traces to Dev Story:** 7.1-readonly-calendar-agenda-view.md
**SRS:** FR-7.1, FR-7.2 in `docs/srs.md`

### Rendering

- [ ] All dated stages appear on their correct calendar day.
- [ ] Month navigation (prev/next) works correctly.
- [ ] List/agenda view matches the same underlying data as the grid.

### Empty State

- [ ] A month with no scheduled stages renders cleanly, no errors.

### Interactions

- [ ] Application deadlines appear on the calendar alongside stages.
- [ ] Clicking an event opens that application's detail panel.
- [ ] Removing a stage event asks for confirmation, then deletes the stage (it disappears from the application's pipeline too).
- [ ] Removing a deadline event asks for confirmation, then clears only the deadline.
- [ ] Cancel in the confirmation leaves everything unchanged.
- [ ] Timed stages show their time; all-day stages show none (story 3.5).

### Regression Sanity

- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
