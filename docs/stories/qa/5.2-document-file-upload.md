# QA: Story 5.2 — Document File Upload — QA Verification

**Epic:** Documents
**Traces to Dev Story:** 5.2-document-file-upload.md

### Upload Happy Path
- [ ] Valid file under the size limit uploads and appears in the list.
- [ ] Uploaded file opens/downloads correctly.

### Rejection Handling
- [ ] Oversized file is rejected with a clear message, no partial record.
- [ ] Unsupported file type is rejected with a clear message.

### Delete Cleanup
- [ ] Deleting an uploaded document removes the underlying storage file, not just the DB row.

### Access Control
- [ ] A user cannot access another user's uploaded file via a guessed or shared URL.

### Mixed List
- [ ] An application with both link-type and upload-type documents displays both correctly.

### Regression Sanity
- [ ] No console errors introduced in the browser during this flow.
- [ ] Data isolation holds — no other user's data is visible or affected.
- [ ] Feature behaves correctly on both desktop and a narrow (mobile-width) viewport, where applicable.
